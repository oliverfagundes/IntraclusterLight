# IntraclusterLight
Projeto de pesquisa das propriedades da Intracluster Light (ICL) na simulação cosmológica magnetohidrodinâmico IllustrisTNG.

O projeto IllustrisTNG pode ser encontrado no site https://www.tng-project.org/

É preciso criar uma conta e logar com e-mail e senha para rodar os códigos na simulação.

A ICL é uma luz muito tênue e difusa, vinda dos aglomerados de galáxias, mas que se origina de estrelas que não pertencem a nenhuma das galáxias pois estão livres orbitando o meio intra-aglomerado. Neste projeto, feito junto ao Observatório Nacional, utilizei python no simulador para investigar as propriedades desta luz tão intrigante.
