# IntraclusterLight
Projeto de pesquisa das propriedades da Intracluster Light (ICL) no simulador magnetohidrodinâmico IllustrisTNG.

O simulador pode ser encontrado no site https://www.tng-project.org/

A ICL é uma luz muito tênue e difusa, vinda dos aglomerados de galáxias, mas que vem de estrelas que não pertencem a nenhuma das galáxias pois estão livres orbitando o meio intra-aglomerado. Neste projeto, feito junto ao Observatório Nacional, utilizei python no simulador para investigar as propriedades desta luz tão intrigante.
